02 / Data handling

No cloud account to breach.

SubDebt writes to the app's private storage on your phone. There is no sign-up, no analytics pipeline, no ad SDK and no server-side copy of your ledger.

The only outbound request is an optional check to GitHub for a new release. It carries no ledger data. Read the full policy →

How SubDebt handles network access, tracking, storage, authentication and exports.
Data path What happens Destination
01 Network Optional check for a new GitHub release. No sync, telemetry or advertising requests. GitHub only
02 Tracking No analytics, advertising IDs, tracking SDKs or behavioral profiles. There is nothing to opt out of. Nowhere
03 Storage Records and receipt photos live in the app's isolated sandbox on your Android device. Your device
04 Auth No account. An optional biometric or PIN lock gates the app, and recents get a privacy overlay. Device hardware
05 Export JSON backup and restore, CSV and PDF files, and PNG snapshot cards — created only when you ask. Where you send it

06 / Questions

The short answers.

The privacy model is simple enough to fit on one page. The support page has the rest.

Support and contact →
Is SubDebt free?

Yes. The app is free, MIT licensed and has no ads. The source is on GitHub.

Does it need an internet connection?

No. The ledger works offline. The app may make one optional request to GitHub to check for a new release, and links you tap open in your browser.

Where is my data stored?

In the app's private storage on your Android device. There is no account and no server copy.

How do I back up or move phones?

Data Vault keeps scheduled local snapshots. Settings exports a JSON backup that restores on another install; CSV and PDF cover statements and records. Keep the file somewhere you trust.

Does it read my SMS or connect to my bank?

No. It does not read messages, link to bank accounts or move money. Bank ledgers are recorded manually.

Is there an iOS version?

No. SubDebt Manager is Android only: com.subdebt.app.

Who builds it?

Zer0k7 Lab. The Android code is public under the MIT license, so the network claims are inspectable.
