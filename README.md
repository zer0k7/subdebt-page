# SubDebt Manager

SubDebt Manager is a private, offline-first personal finance manager for Android. It helps people keep track of recurring subscriptions, personal debt, credit ledgers, and everyday spending without requiring an account or sending financial records to a remote service.

## Highlights

- Subscription tracking from weekly to yearly billing cycles
- Renewal dates, monthly burn rate, and on-device reminders
- Separate ledgers for borrowed liabilities and lent assets
- Partial settlements with live balance changes
- Categorized daily spending and monthly thresholds
- A 30-day spending heatmap
- Offline persistence with no account requirement
- Biometric lock, JSON backup and restore, and CSV export

## Privacy

SubDebt is designed to keep financial data on the device. The product does not require an account and is presented as operating without a remote server, analytics, or telemetry.
